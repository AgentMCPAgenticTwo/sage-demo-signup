# Modules

* [App Shell](/modules/src-app.md) - Document shell, React root and the route table that maps a path to a page component.
* [Pages](/modules/src-pages.md) - The four routed screens: sign up, log in, reset password and welcome.
* [Components](/modules/src-components.md) - Shared presentational primitives: Card, Field, Message and PasswordRules.
* [Router](/modules/src-router.md) - Minimal history-based router exposing navigate, usePath and Link.
* [Store](/modules/src-store.md) - Demo-only account persistence over localStorage and sessionStorage.
* [Styles](/modules/src-styles.md) - Single global stylesheet defining the semantic class names the components use.
* [Build Config](/modules/build-config.md) - Vite configuration, package scripts and declared dependencies.
* [Maintenance Metadata](/modules/maintenance-metadata.md) - Generated correction, prompt and workflow artefacts kept alongside the source.
