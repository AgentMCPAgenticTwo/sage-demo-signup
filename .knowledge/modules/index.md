# Modules

* [src](/modules/src.md) - Application shell: HTML entry, React root and the route table.
* [src/pages](/modules/src-pages.md) - The three screens of the sign-up flow, one default-exported component per file.
* [src/components](/modules/src-components.md) - Presentational primitives shared by every page: Card, Field and Message.
* [src/router](/modules/src-router.md) - Hand-rolled History-API router: navigate, usePath and Link.
* [src/store](/modules/src-store.md) - Demo-only account store backed by localStorage and sessionStorage.
* [build](/modules/build.md) - Vite build configuration and the generated dist bundle.
