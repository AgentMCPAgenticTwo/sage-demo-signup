# Modules

* [src (app shell)](/modules/src-app-shell.md) - Bootstraps React and maps the current path to a page component.
* [src/pages](/modules/src-pages.md) - The three routed screens: sign up, log in and the signed-in welcome page.
* [src/components](/modules/src-components.md) - Presentational primitives shared by every page: Card, Field and Message.
* [src/router.jsx](/modules/src-router.md) - Minimal pushState router providing navigate, usePath and Link.
* [src/store.js](/modules/src-store.md) - Demo-only account store over localStorage and sessionStorage.
